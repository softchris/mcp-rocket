# mcp-rocket

A scaffolder app that streamlines the setup of MCP (Model Context Protocol) projects.

## What it does

This tool automates the complete setup process for MCP projects by:

1. **Creates a directory** - Sets up a new project directory structure
2. **Sets up Python project with uv** - Initializes a Python project using the uv package manager
3. **Installs MCP dependencies** - Automatically installs all required MCP dependencies
4. **Opens VS Code** - Launches VS Code with your newly created project ready to go
